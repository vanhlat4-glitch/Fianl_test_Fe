# EDUCORE SYSTEM - FRONTEND (REACT + VITE)

Giao diện Quản trị Trường học **EduCore System** kết nối với Backend API (`http://localhost:5001`).

## Cách cài đặt & chạy Frontend độc lập
```bash
npm install
npm run dev
```
Truy cập tại: **`http://localhost:5173`**

## Các chức năng chính
- **Đăng nhập / Đăng xuất** & **Chế độ Sáng / Tối (Light / Dark Mode)**
- **Thống kê tổng quan**: Biểu đồ & số liệu Giáo viên, Vị trí công tác, Học sinh, Lớp học.
- **Quản lý Giáo viên**: Danh sách phân trang, Tìm kiếm đa năng, Tạo mới kèm Upload ảnh đại diện, Khai báo nhiều bằng cấp (Học vị), Xem chi tiết, Cập nhật / Thăng chức, Xóa.
- **Quản lý Vị trí công tác**: Danh sách vị trí, Tìm kiếm, Tạo mới, Cập nhật & Bổ nhiệm giáo viên cũ lên chức vụ mới, Xóa.
- **Quản lý Lớp học & Học sinh**: Tìm kiếm, thêm mới, xóa.
